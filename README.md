# Used Car Price Prediction Engine

Supervised Machine Learning web app predicting used car prices based on age, mileage, fuel type, transmission, and engine capacity.

## Features
- **Data Pipeline**: Automated generation of automotive dataset.
- **Model**: Multiple Linear Regression with categorical encoding and scaling.
- **UI**: Interactive Streamlit interface.

## Quickstart
1. `pip install -r requirements.txt`
2. `python train.py`
3. `streamlit run app.py`
